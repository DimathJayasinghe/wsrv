# wsrv: logo and brand

## 1. The logo
- **Idea**: a circle (the browser) and a square (the server) share a window: the connection between them. One flat shape with one real hole.
- **Versions**: horizontal (primary) · stacked · symbol · wordmark. Ink on light, white on dark. The *lit* version (amber window) is optional, for places with room: app icon, docs header, social card.
- **Files**: `svg/` masters (use these; the README uses `wsrv-horizontal.svg` and, on a dark theme, `wsrv-horizontal-white.svg`) · `web/` favicon, Apple touch icon, PWA icons, manifest and the `<head>` snippet · `variants/` one-colour black, brand-colour, square and app-icon versions. `social-preview.png` (1280x640) is the image for the repository's social preview (GitHub: Settings, General, Social preview).

## 2. Clear space
Keep a clear zone of **1 × the circle's radius** (about 27 % of the symbol's height) on every side. The zone scales with the logo.

## 3. Minimum size
| Version | Screen | Print |
|---|---|---|
| Horizontal | 96 px wide | 25 mm wide |
| Symbol | 24 px (use `wsrv-symbol-small.svg` below 32 px; the favicon files already do) | 6 mm |

## 4. Colour
| Name | HEX | RGB | CMYK (approximate) |
|---|---|---|---|
| Ink | #0B1220 | 11, 18, 32 | 66 / 44 / 0 / 87 |
| Signal amber | #FFB020 | 255, 176, 32 | 0 / 31 / 87 / 0 |
| White | #FFFFFF | 255, 255, 255 | 0 / 0 / 0 / 0 |

Pantone: not assigned; match the Ink and Amber values on a proof before a print run.
**Approved pairs**: ink on white or light grey · white on ink · white on any dark colour. The ink mark disappears on near-black: use the white version there.

## 5. Typography
The wordmark is drawn as paths: do not retype it. For text beside the logo use a neutral sans (Inter or the system UI font).

## 6. Don'ts
Don't stretch or rotate · don't recolour outside the palette · don't light the window in any colour but amber · don't add shadows, outlines or gradients · don't separate the circle from the square · don't place the ink mark on a dark or busy background · don't retype the wordmark.

## 7. Notes
- **Favicons**: `web/favicon.svg` follows the browser's light or dark theme. The `.ico` and PNG favicons are the white mark on an ink tile, so they show on both.
- **Trademark**: this kit has not been searched. Run a trademark and reverse-image search before wider commercial use.
- **Files**: masters are flat SVG paths (no text, no filters). `svg/wsrv-symbol-small.svg` is the cut for 16 to 32 px: a larger shared window and a heavier square.
