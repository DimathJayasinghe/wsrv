wsrv quickstart

This page talks to the wsrvd daemon over a WebSocket; a PHP worker answers.

1. Connect

not connected

Another port? Run compose with WSRV_PORT=18080 and use ws://localhost:18080/ here.

2. Send a message

The worker echoes it back.

3. Join a room, then publish from outside

In a terminal, as a controller or a queue job would:

docker compose run --rm worker php /app/publish.php room.1 "hello from outside"

What the page sees

    Now try docker compose restart wsrvd: the page reconnects and joins the room again by itself.
